## Monetización
El sitio está preparado para añadir AdSense, pero no debe añadirse un publisher ID inventado. Cuando exista un ID real, añadir la etiqueta de AdSense y la línea correspondiente de ads.txt exactamente como aparezcan en la cuenta.
